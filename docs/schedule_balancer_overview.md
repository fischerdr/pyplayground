# Namespace Schedule Balancer Script (`k8s_schedule_balancer.py`)

## Purpose

This script distributes Kubernetes namespaces across a specified number of groups (e.g., backup schedules) based on their resource consumption. The goal is to create balanced groups, ensuring that no single group/schedule handles a disproportionately large load. Balancing is based on a calculated `weight` derived from PersistentVolumeClaim (PVC) capacity, core resource requests (CPU/memory), and custom resource sizes.

## How it Works

1. **Input:** Reads namespace resource data from a CSV file (typically generated by `k8s_rcrscountsize.py`).
2. **Weight Calculation:** For each namespace, calculates a `weight` using configurable multipliers for different resource types (PVC GiB, Core Resource KiB, Custom Resource KiB). Missing or invalid size data defaults to 0 for weight calculation.
3. **Sorting:** Sorts namespaces in descending order based on their calculated weight.
4. **Greedy Balancing:** Iterates through the sorted namespaces and assigns each one to the group currently having the lowest total accumulated weight.
5. **Output:**
    * Generates a JSON file detailing the assigned namespaces and aggregated resource sums for each group.
    * Prints a summary table to the console using the `rich` library.
    * Generates a text file containing the same summary information.

## Inputs

The script uses command-line arguments (via `click`):

* `--input-csv` (Required): Path to the input CSV file. Must contain a "Namespace" column and can include `TotalPVCCapacityGiB`, `TotalCoreResourcesSizeKiB`, `TotalCustomResourceSizeKiB`.
* `--num-groups` (Required): The desired number of balanced groups to create. Must be > 0.
* `--weight-pvc-gib` (Optional, Default: 1048576): Multiplier for `TotalPVCCapacityGiB`. Default value equates 1 GiB PVC to 1 MiB of core/custom resources (1 *1024* 1024).
* `--weight-core-kib` (Optional, Default: 1): Multiplier for `TotalCoreResourcesSizeKiB`.
* `--weight-custom-kib` (Optional, Default: 1): Multiplier for `TotalCustomResourceSizeKiB`.
* `--output-json` (Optional, Default: `tmp/schedule_groups.json`): Path for the output JSON file.
* `--output-summary` (Optional, Default: `logs/schedule_summary.txt`): Path for the output summary text file.

## Outputs

* **JSON File:** A dictionary where keys are group names (e.g., "group_0", "group_1") and values contain:
  * `namespaces`: List of namespace names assigned to the group.
  * `namespace_count`: Number of namespaces in the group.
  * `total_calculated_weight`: Sum of weights of namespaces in the group.
  * `sum_pvc_gib`, `sum_core_kib`, `sum_cr_kib`: Sums of original resource sizes for the group.
* **Console Output:** A formatted table summarizing the key metrics for each group.
* **Summary Text File:** A text file containing the same information as the console table.

## Weighting Considerations

The effectiveness of the balancing depends heavily on the chosen weight multipliers. The defaults heavily prioritize PVC capacity. Adjust these multipliers based on which resources are most critical or constrained in your environment (e.g., backup transfer time correlated with PVC size, scheduling constraints related to core resources).

## Dependencies

* Python 3.x
* `click` library (`pip install click`)
* `rich` library (`pip install rich`)

## Usage Example

```bash
python src/k8s_schedule_balancer.py \
    --input-csv data/namespace_sizes.csv \
    --num-groups 5 \
    --weight-pvc-gib 1048576 \
    --output-json output/balanced_schedules.json \
    --output-summary output/schedule_summary.txt
```

## Error Handling

The script includes error handling for:

* File not found errors.
* Invalid CSV formats (e.g., missing "Namespace" column).
* Non-numeric or missing size data (defaults to 0 with a warning).
* Issues writing output files.
Errors during critical processing (CSV reading, JSON writing) will cause the script to exit with an error code, while errors writing the non-essential summary text file will be logged and reported but allow the script to finish. Log messages are written to `logs/k8s_schedule_balancer.log`.
